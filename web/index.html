An AI referee, checked by code

Every number checked. Every claim questioned. Every result re-run.

Peer review rarely has time to check every number or re-run every result, so mistakes get through. Give this auditor a paper: it reads it the way a referee does, argues against its own criticism before keeping it, does the arithmetic in code, and rebuilds the computations from the paper's equations.

    How it works

    Models propose; code checks.

    Reads the paper

    The LaTeX source from arXiv, or the PDF transcribed page by page. Figures are described from their images.

    Done by MiniCPM-V

    Checks the numbers

    Averages and totals in tables, percentages against their counts, the abstract's figures against the body.

    Done by code, never a model

    Writes a referee report

    Summary, concerns, a reproducibility checklist and questions. Every concern must quote the paper.

    Done by Nemotron 3 Ultra

    Finds related work

    Searches the web for the closest papers, and checks whether the paper cites them.

    Done by Tavily and Nemotron 3 Ultra

    Argues against itself

    Each concern is challenged. It stays only if no passage of the paper answers it, and a second model agrees.

    Done by Nemotron 3 Ultra, then Super

    Re-runs the results

    For computational papers: scripts written from the equations are run and compared with the paper's tables.

    Done by Nemotron 3 Super; verdicts by code
